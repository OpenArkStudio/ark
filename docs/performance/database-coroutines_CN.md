# 数据库回调与协程性能

ark 私有数据库服务的同等工作量对比：**56 组配对配置、336 个独立进程、零错误**。每种方式按固定操作数运行三次，使用 Boost.Asio；这里测量 ark 的 `database_awaitable`、`manual_runtime` 与任务组接入，不是 arknet 原生协程接口。

图中柱高为三次测量的中位数，短误差线为最小值至最大值；各面板纵轴独立。横轴为**连接数／在途请求数**。表中变化＝（协程中位数／回调中位数−1）×100%。


<Aside type="note" title="统计口径">

P50 与各指标精确值见完整表。P99 先按每进程全部请求取第 99 百分位，再取三个进程的中位数，不混合进程样本。RSS 是含预热、预分配延迟样本的整进程高水位；回调也创建空闲桥接／任务对象，不能隔离协程帧成本。

</Aside>
