# 基准测试与容量验收

正确性、组件开销与部署容量回答不同的问题。

| 验证 | 范围 |
| --- | --- |
| C++ 回归测试 | 消息正确性、重连、关闭与回调行为 |
| 本地组件基准 | 收包缓冲申请、拆包与私有数据库调用开销 |
| 跨机器负载与长时间运行 | 目标负载下的吞吐量、延迟、CPU、内存与故障恢复 |

部署目标为多进程下 10–20 万同时连接，尚非单进程容量结论。测量前确定消息频率、包体大小、进程数、连接分布与故障条件。

正确性检查见[网络回归测试](../networking_CN.md)，传输层测量见 [arknet 性能报告](https://openarkstudio.github.io/arknet/zh/performance/)。TODO：发布完整的跨机器部署验收报告。

## 应用收包缓冲测量

[收包缓冲报告](receive-buffers_CN.md)用 C++ 基准对比 4、64、512 KiB 初始容量，记录机器、中位数、范围与吞吐回退；不能代替跨机器负载验收。

## 数据库回调与协程测量

[数据库报告](database-coroutines_CN.md)对比 ark 私有服务、手动执行器和任务组中的回调／Asio 协程：56 组配置、336 个独立进程，两种包体、连接／在途限额及连续／1 ms 更新。SVG 展示吞吐与 CPU；响应时间、进程内存与完整表可展开。本机短时数据不代表部署容量。
